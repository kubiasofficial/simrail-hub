# SimRail Hub 0.7.0 — Trať pod dohledem

![SimRail Hub 0.7.0](https://github.com/kubiasofficial/simrail-hub/releases/download/v0.7.0/SimRail-Hub-0.7.0-banner.png)

Výraznější palubní displej, volitelný informační dispečer a první náhled připravované tratě.

- **Palubní počítač:** větší následující zastávka, příjezd a odjezd vedle ní, rozlišení plánu a odhadu. Výraznější zpoždění, jemné animace a stavy STOJÍ / NA TRATI / VE STANICI.
- **Čistší přehled:** malá mapa v palubním počítači; celý jízdní řád otevřete na vyžádání.
- **Informační dispečer BETA:** volitelné zprávy o pomalém provozu před vlakem. Dosah 2 / 5 / 10 km, samostatná hlasitost hlasu a vysílačky. Pulz na mapě zůstává do potvrzeného uklidnění; při chybějících datech je označen jako neověřený. Jde o orientační informace, nikoli řízení provozu.
- **Sneak peek:** vrstva Lublin Region Dęblin–Lublin–Chełm, výchozí vypnutá. Orientační průběh skutečné železnice podle OSM s oficiálními informacemi o DLC; nejde o potvrzenou herní geometrii.
- **Zvuk:** stejný gong lze zapnout před i po hlášení. Hlas, gong a vysílačka mají vlastní hlasitost. Podpora místních nahrávek pro 35xx / 53xx / 45xx / 54xx a jejich pětimístné varianty; hlasové soubory zůstávají soukromé a nejsou součástí vydání.
- **Novinky:** obrázkové okno po prvním spuštění aktualizované verze; znovu ho otevřete z Domů → Prohlédnout novinky. Animace respektují nastavení, minimalizaci a omezení pohybu.

## Aktualizace

U instalační verze otevřete v launcheru kontrolu aktualizací. Po stažení zvolte **Restartovat a aktualizovat**. Běžící 0.6.0 používá své dosavadní oznámení; nové obrázkové okno uvidíte po přechodu na 0.7.0. Portable verze vyžaduje stažení nového portable souboru, případně jednorázovou instalaci Setup verze pro budoucí automatické aktualizace.

Dispečera zapnete v palubním počítači, náhled tratí přes Živá mapa → Vrstvy a vzhled. Soukromá nastavení ani nahrávky se při aktualizaci nemažou. Aplikace je zdarma a nevyžaduje novou placenou službu.

Grafika banneru vznikla s imagegen ze skutečného herního snímku EU07-068 ze SimRail Wiki. Neoficiální komunitní projekt; není spojen s vývojářem hry SimRail.
